Bootstrap5｜「コンテナ」を使ってみた

カテゴリ：Web制作 投稿日：2026年11月22日

はじめに

Bootstrap5を学習している中で、「コンテナ（container）」というクラスが頻繁に登場することに気付きました。

最初は「何のために使うのだろう？」と思っていましたが、実際に試してみると、ページレイアウトを整えるための重要な役割を持っていることが分かりました。

今回はBootstrap5のコンテナについて、基本的な使い方と実際に触ってみた感想をまとめます。

コンテナとは何か

コンテナは、Bootstrapでコンテンツを配置するための土台となる要素です。主な役割は以下のとおりです。

  • コンテンツの横幅を制御する
  • 左右に適切な余白を確保する
  • 画面サイズに応じてレイアウトを調整する
  • グリッドシステム（row・col）の親要素として利用する

Bootstrapでは次のような構造がよく使用されます。

<div class="container">
  <div class="row">
    <div class="col">
      コンテンツ
    </div>
  </div>
</div>

コンテナがあることで、画面いっぱいに広がり過ぎることなく、見やすいレイアウトを作ることができます。

どんな場面で活用できるのか

コンテナは様々な場面で活用できます。

・サイト全体のレイアウト

<div class="container">
  サイト全体の内容
</div>

コンテンツを中央寄せにしたい場合に便利です。

・セクションごとのレイアウト

<section class="container">
  サービス紹介
</section>

<section class="container">
  会社概要
</section>

各セクションを独立して管理できます。

・グリッドシステムとの組み合わせ

<div class="container">
  <div class="row">
    <div class="col-md-6">左</div>
    <div class="col-md-6">右</div>
  </div>
</div>

2カラムや3カラムなどのレイアウトを簡単に実現できます。

基本的な実装方法

Bootstrapには主に2種類のコンテナがあります。

container

<div class="container">
  ...
</div>

画面サイズに応じて最大幅が設定されます。企業サイトやブログなどでよく利用されます。

container-fluid

<div class="container-fluid">
  ...
</div>

常に画面幅いっぱいまで広がります。ダッシュボードや管理画面などで利用されることが多いです。

コード例と動作例

以下のコードを作成して動作を確認してみました。

<div class="container border">
  <div class="row">
    <div class="col-md-6 bg-light">
      左側のコンテンツ
    </div>
    <div class="col-md-6 bg-secondary text-white">
      右側のコンテンツ
    </div>
  </div>
</div>

表示結果は次のようなイメージになります。

+--------------------------------------+
| container                            |
|                                      |
|  +--------------+-----------------+  |
|  | 左側         | 右側            |  |
|  +--------------+-----------------+  |
|                                      |
+--------------------------------------+

画面幅が狭くなると、Bootstrapのレスポンシブ機能によって自動的に縦並びへ切り替わります。

実際に触ってみて感じたこと

最初は「グリッドシステムだけ覚えればよいのでは？」と思っていました。

しかし実際に試してみると、コンテナがあることで適切な余白や横幅が自動で設定されるため、自分で細かくCSSを書く手間を減らせることが分かりました。

また、コンテナはページに1つだけではなく、複数配置できることも学びました。例えば以下のように、用途に応じて使い分けられます。 

<header class="container-fluid"></header>

<section class="container"></section>

<section class="container"></section>

<footer class="container-fluid"></footer>

個人的には、HTMLとCSSで作成していた .wrapper { max-width: 1200px; margin: 0 auto; } に近い役割だと感じました。

まとめ

Bootstrap5のコンテナは、レイアウトの土台となる重要な要素です。

今回学んだポイントは次のとおりです。

  • コンテンツの横幅や余白を調整できる
  • グリッドシステムの親要素として利用する
  • container と container-fluid の2種類がある
  • ページ内に複数配置しても問題ない
  • CSSのラッパー要素（wrapper）のような役割を持つ

Bootstrapを使い始めたばかりの頃は「row」や「col」に注目しがちですが、その土台となる「container」の役割を理解することで、レイアウト全体の仕組みが見えやすくなりました。

今後も実際に手を動かしながらBootstrapの各機能を試していきたいと思います。
